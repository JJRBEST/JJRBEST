## 🔬 Current Exploration: Quantum × Embedded Software
Quantum computers face a strikingly similar resource problem:
qubits are expensive, unstable resources, QPU calls carry latency,
and the classical control layer needs precise coordination —
challenges that mirror what embedded software engineers deal with
every day.

I'm currently exploring hybrid quantum-classical architectures,
applying lessons from resource-constrained embedded systems to
the classical control layer and edge deployment of quantum workloads.
